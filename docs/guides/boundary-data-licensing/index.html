Licensing world boundary data: Natural Earth and public domain

Applies to @cublya/world-atlas 3.0.0-beta.2, built from Natural Earth 5.1.2. Other datasets' terms checked 18 October 2026. This is a summary of published terms, not legal advice.

The TopoJSON files in this package are derived from Natural Earth, which declares all of its map data to be in the public domain. You can use them in commercial products, modify them and redistribute them, without asking permission and without crediting anyone. The repository's build code is separately licensed under ISC. Neither licence decides whether a border is drawn the way your readers expect; that is an editorial choice you still have to make.

What the data licence says

The package's DATA_LICENSE.md states:

The generated TopoJSON artifacts in this package are derived from Natural Earth vector data version 5.1.2.

Natural Earth declares all versions of its raster and vector map data to be in the public domain. Permission and attribution are not required, including for commercial use, modification, and redistribution.

Source: <https://www.naturalearthdata.com/about/terms-of-use/>

The repository's build code is separately licensed under the ISC license in LICENSE.

That follows Natural Earth's own terms of use: "All versions of Natural Earth raster + vector map data found on this website are in the public domain. You may use the maps in any manner, including modifying the content and design, electronic dissemination, and offset printing." The terms add: "No permission is needed to use Natural Earth. Crediting the authors is unnecessary."

Natural Earth uses the words "public domain" rather than a specific public domain dedication such as a Creative Commons tool. When you record the licence in a manifest, an SBOM or structured data, point to Natural Earth's terms page rather than substituting another licence's URL.

Two licences, two kinds of file

WhatWhereTermsWhat you must do
TopoJSON data countries-*.json, land-*.json Public domain, per Natural Earth Nothing. Credit is optional.
Build code scripts/ in the repository ISC licence, in LICENSE Keep the copyright and permission notice in copies of the code.

The npm package contains the data files, source.json, DATA_LICENSE.md, the README and the ISC LICENSE file, but no build scripts. npm always includes a package's README and LICENSE (npm docs, files), which is why the code licence travels with a data-only package. If you only ship the JSON files, the ISC terms have nothing to attach to. For the same reason, the "license": "ISC" field in package.json describes the code only; the data's terms are in DATA_LICENSE.md.

Should you credit Natural Earth anyway?

You do not have to. If you want to, Natural Earth suggests two forms on its terms page:

  • Short: "Made with Natural Earth."
  • Long: "Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com."

A credit in a map's footer or an about page is cheap and tells readers where the borders came from, which matters when someone disagrees with one. It also helps later maintainers, since source.json pins the exact Natural Earth version ("naturalEarthVersion": "5.1.2") the files were built from.

What public domain does not settle

Accuracy

Natural Earth's terms say the authors "are not responsible for any problems relating to accuracy, content, design, and how it is used." The data is generalized for small-scale maps, and that shows as soon as you test points against it. Checked with d3-geo's geoContains on this package's files: in the 110m file, Geneva falls inside France, Singapore inside Malaysia and Montevideo in the sea; in the 50m file, El Paso falls inside Mexico (boundary-checks.mjs). Do not use these files to decide which side of a border a location is on when the answer has legal or financial consequences.

Where the borders are

Natural Earth draws boundaries by de facto control. In its words, "We show who actually controls the situation on the ground," and it publishes separate point-of-view variants for several dozen countries (Admin 0 countries).

This package then applies one of two documented views:

Areas are measured on the 50m files with d3-geo's spherical geoArea (boundary-checks.mjs). "UN-style" describes this project's policy; the files are not official United Nations cartographic products. Every country feature carries properties.boundaryView, and merged features in the default view list what was merged in properties.policyMergedMapUnits, so you can check which view a running app is using.

No licence makes a border uncontroversial. Readers notice how disputed areas are drawn, and some will tell you. Choose a view on purpose, say which one on the map or its about page, and if your product needs a different decision for a specific area, edit the geometry in your data layer rather than in rendering code.

The data you put on the map

A choropleth combines boundaries with values from somewhere else. The boundaries being public domain does not change the terms of the values: if your statistics come under a licence that requires attribution, the finished map still needs it.

How other boundary datasets compare

If you are choosing a source, the licence often decides it before the geometry does. The summaries below quote each publisher's own page.

DatasetLicence as publishedMain obligation
Natural Earth Public domain None
geoBoundaries (gbOpen) CC BY 4.0: "the only requirement for use is acknowledgement" Attribution in products that use it
OpenStreetMap Open Database License (ODbL) Credit OpenStreetMap and its contributors; altered data may be distributed "only under the same license"
GADM "Freely available for academic use and other non-commercial use" "Redistribution or commercial use is not allowed without prior permission"

These datasets also differ in purpose. geoBoundaries and GADM cover subnational administrative levels as well as countries; Natural Earth is built for small-scale world cartography at three fixed scales. For a world map of countries in a commercial product, Natural Earth's terms are the least restrictive of the four.

Checklist for shipping a map

  • Data files only: no licence obligations. Optional credit: "Made with Natural Earth."
  • Copying or modifying the build scripts: keep the ISC notice.
  • Recording the licence in metadata: link Natural Earth's terms page.
  • Boundary view chosen deliberately and stated on the map or its about page.
  • Licences of the values you join checked separately.
  • Natural Earth version recorded (source.json), so the geometry can be traced.
